# Tricolor Clock

Each 12-hour clock time is a tricolor flag — H:MM

### Digits

<img src="swatch-0.png" alt="0 = white #FFFFFF" width="64"> <img src="swatch-1.png" alt="1 = red #E40303" width="64"> <img src="swatch-2.png" alt="2 = tangerine #F45A00" width="64"> <img src="swatch-3.png" alt="3 = gold #FFAA00" width="64"> <img src="swatch-4.png" alt="4 = yellow #FFED00" width="64"> <img src="swatch-5.png" alt="5 = lime #8DB813" width="64"> <img src="swatch-6.png" alt="6 = green #008026" width="64"> <img src="swatch-7.png" alt="7 = cyan #00AAAA" width="64"> <img src="swatch-8.png" alt="8 = azure #0088CC" width="64"> <img src="swatch-9.png" alt="9 = blue #004DFF" width="64"> <img src="swatch-a.png" alt="10 = indigo #3A34D6" width="64"> <img src="swatch-b.png" alt="11 = violet #6425CB" width="64">

Colors 10 and 11 are only used for the hour, never for the minutes. Hour 0 stands in for 12.
